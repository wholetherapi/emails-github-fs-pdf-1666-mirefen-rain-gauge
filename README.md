# Mirefen Rain Gauge — Design Package

Released design package for the **Mirefen Rain Gauge, Revision 2** (internal design ID
`MRG-2`).

## What is included
- `hardware/` — KiCad schematic and board for the counter and heater controller
- `firmware/` — tipping-bucket debounce and heater control firmware
- `docs/` — bill of materials and calibration procedure
- `enclosure/` — funnel, bucket and heater notes

## Release status
The MRG-2 package shipped in September 2026 and all fabrication files are final. This
repository is the authoritative design package; a separate repository only mirrors
documentation.
